## 项目特色

- 🎁 **多奖池管理**: 支持创建多个奖池，每个奖池独立设置价格和概率
- 💳 **双模式抽奖**: 支持兑换码抽奖和余额抽奖两种方式
- 🎯 **保底机制**: 可设置保底次数，连续未中后必中保底奖品
- 📊 **数据统计**: 完整的抽奖记录、中奖记录、余额明细统计
- 📧 **邮件验证**: 注册时发送邮箱验证码，提升账号安全性
- 💰 **充值管理**: 支持在线充值，余额调整，充值记录查询
- 🎨 **精美界面**: 采用毛玻璃效果设计，响应式布局，支持深色/浅色主题
- 📱 **移动端适配**: 完美支持手机、平板、电脑等多设备访问
- 🔧 **后台管理**: 功能强大的后台管理系统，支持所有配置在线修改

## 技术栈

- **后端**: PHP 8.0+
- **数据库**: MySQL 5.7+ / MariaDB 10.2+
- **前端**: HTML5 + CSS3 + JavaScript
- **第三方库**:
  - PHPMailer (邮件发送)
  - Chart.js (数据统计图表)
  - xf-MusicPlayer (音乐播放器)

## 数据库设计

### 主要数据表

1. **admin** - 管理员表
   - 管理员账号密码
   - 登录验证

2. **config** - 站点配置表
   - 站点名称、描述、LOGO
   - ICP备案号
   - 自定义字体设置

3. **users** - 用户表
   - 用户基本信息(邮箱、昵称、密码)
   - 用户余额、状态、验证状态
   - 注册时间

4. **pools** - 奖池表
   - 奖池名称、抽奖价格
   - 保底设置、活动状态

5. **prizes** - 奖品表
   - 奖品名称、图片、概率
   - 奖品类型(实物/虚拟/保底)

6. **card_codes** - 兑换码表
   - 卡密内容、使用状态
   - 关联奖品ID

7. **winners** - 中奖记录表
   - 用户中奖记录
   - 奖品信息、中奖时间

8. **balance_logs** - 余额日志表
   - 用户余额变动记录
   - 变动类型、金额、备注

9. **email_config** - 邮件配置表
   - SMTP服务器配置
   - 发件人信息、验证码有效期

10. **email_codes** - 邮件验证码表
    - 验证码、关联邮箱
    - 验证码类型、过期时间

## 功能详解

### 1. 抽奖系统

**兑换码抽奖**
- 用户输入兑换码进行抽奖
- 系统验证兑换码有效性
- 根据奖品概率随机抽取
- 扣减卡密库存，记录中奖信息

**余额抽奖**
- 用户使用账户余额进行抽奖
- 支持单次抽奖和连续抽奖
- 实时扣除抽奖费用
- 保底机制自动触发

**保底机制**
- 可设置保底次数(如10次未中必中保底奖品)
- 统计用户连续未中次数
- 达到保底次数时自动触发保底奖品
- 中奖后重置保底计数

### 2. 用户系统

**注册流程**
- 邮箱注册，发送验证码
- 验证码5分钟有效
- 防重复注册、防恶意刷注册

**登录系统**
- 邮箱密码登录
- 密码加密存储(password_hash)
- Session会话管理

**用户管理**
- 后台可查看所有用户
- 支持新增用户、编辑用户、封禁用户
- 支持调整用户余额
- 支持修改用户注册时间

### 3. 奖池管理

**奖池配置**
- 创建多个独立奖池
- 设置奖池名称、抽奖价格
- 配置保底机制
- 控制奖池开启/关闭

**奖品管理**
- 添加奖品到奖池
- 设置奖品概率(总和为100%)
- 上传奖品图片
- 设置奖品类型(普通/保底)

**概率控制**
- 概率总和自动校验
- 支持百分比精确到小数点
- 保底奖品独立概率设置

### 4. 兑换码系统

**批量生成**
- 支持批量导入兑换码
- 每行一个卡密
- 自动去重、格式校验

**卡密管理**
- 查看卡密使用状态
- 查看卡密关联奖品
- 统计未使用卡密数量

### 5. 统计图表

**数据概览**
- 用户注册统计(日/月/年)
- 充值金额统计(日/月/年)
- 中奖记录统计
- 使用Chart.js绘制折线图

**实时统计**
- 用户总数、在线用户
- 今日注册、今日充值
- 今日抽奖、今日中奖

## 安装部署

### 环境要求

- PHP >= 8.0
- MySQL >= 5.7 或 MariaDB >= 10.2
- Apache/Nginx
- PHP扩展: PDO, PDO_MySQL, GD, cURL, OpenSSL

### 快速安装

1. **下载源码**
```bash
git clone https://github.com/HeLeiawa/lucky-Lottery.git
cd lucky-lottery
```

2. **上传网站文件**
将所有文件上传到您的网站根目录

3. **访问安装程序**
在浏览器中访问 `http://你的域名/install/index.php`，按照页面引导完成安装

4. **登录后台**
安装完成后，访问 `http://你的域名/admin/`


**注意**: 首次登录后请立即修改默认密码！

## 配置说明

### 邮件配置

在后台 `邮件设置` 中配置SMTP信息:

- SMTP服务器: 如 smtp.qq.com
- SMTP端口: 465(SSL) 或 587(TLS)
- 发件邮箱: 您的邮箱
- 授权码: 邮箱授权码(非登录密码)
- 发件人名称: 系统名称

### 支付配置

在后台 `支付设置` 中配置支付接口:

- 支付宝商户ID、应用密钥
- 微信商户号、API密钥
- 支付回调地址自动生成

### 安全建议

1. **修改默认密码**: 首次登录后立即修改管理员密码
2. **保护后台目录**: 修改admin目录名称或添加IP白名单
3. **启用HTTPS**: 配置SSL证书，强制HTTPS访问
4. **定期备份**: 定期备份数据库和上传文件
5. **文件权限**: 确保敏感目录不可被直接访问

## 常见问题

**Q: 抽奖概率不准确?**
A: 请检查奖池中所有奖品概率总和是否为100%

**Q: 保底机制不生效?**
A: 确保已设置保底次数，并且有设置保底奖品

**Q: 邮件发送失败?**
A: 检查SMTP配置是否正确，端口是否开放，授权码是否有效

**Q: 充值回调未成功?**
A: 检查支付回调地址是否正确，服务器是否可被外网访问

**Q: 如何修改网站字体?**
A: 将TTF字体文件上传到 `/ttf/` 目录，在后台站点配置中选择字体
